🚗 Reliant Rental – Vehicle Rental System

Reliant Rental is a simple and efficient vehicle rental web application built using HTML, CSS, JavaScript, and a Node.js + MySQL backend.
This system allows users to browse vehicles, make bookings, and manage rentals, while admins can manage vehicle data.

📌 Features

User registration & login

Browse and search vehicles

Book vehicles online

View booking history

Admin: Add / update / delete vehicles

REST API built with Express.js

🛠️ Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MySQL
